BRASÕES — NOVAS REGRAS
======================

1) GITHUB: cada arquivo vai para a MESMA pasta em que está no zip
   raiz:   admin.html, app.html, brasoes.html, login.html, master.html, rede.html
   js/:    admin.js, brasoes.js, brasoes-admin.js, login.js, rede.js
   css/:   admin.css
   (No GitHub: abra a pasta → Add file → Upload files.)

2) FIREBASE → Firestore → Regras: cole o firebase/firestore.rules inteiro → Publicar.
   Sem isso, o Admin não consegue conceder brasões automáticos.

3) Na primeira vez que o Admin ou o Mestre Profeta abrir a página Brasões,
   a trava do "Mestre / Presidente" é gravada no Mestre Profeta.
   (Configurações → Presidente do Grupo mostra quem está travado.)
