REGRA DO FIREBASE STORAGE — fotos da Rede Liberdade (rede.html)
================================================================
Onde: Firebase Console → Storage → Regras. Cole o bloco "match /rede/..."
DENTRO do "match /b/{bucket}/o { ... }" já existente, sem apagar o que já
está lá (as regras das fotos de perfil continuam iguais). Depois, Publicar.

    // Fotos dos posts da Rede Liberdade: cada pessoa só grava na própria
    // pasta (rede/<uid>/...), imagens de até 2 MB; qualquer logado lê.
    match /rede/{uid}/{arquivo} {
      allow read: if request.auth != null;
      allow write: if request.auth != null
                   && request.auth.uid == uid
                   && request.resource.contentType.matches('image/.*')
                   && request.resource.size < 2 * 1024 * 1024;
    }

Sem essa regra, o post com texto funciona normalmente, mas a foto não sobe
(o app avisa "confira as regras do Storage").
